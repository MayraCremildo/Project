# Almeida & Costa — Site de Advocacia

Site institucional responsivo criado com HTML, CSS e JavaScript.

## Como visualizar
Abra o ficheiro `index.html` no navegador ou publique o repositório com GitHub Pages.

## Personalizações necessárias antes de publicar
- Substituir o nome fictício "Almeida & Costa" pelo nome real do escritório.
- Atualizar contactos, telefone, e-mail, endereço e horários no rodapé.
- Confirmar nomes, fotografias, cargos e áreas de atuação da equipa.
- Substituir os depoimentos de demonstração por avaliações reais autorizadas.
- Ligar o formulário a um serviço de envio ou backend. Atualmente ele apenas apresenta uma mensagem demonstrativa.
- Rever textos e informações jurídicas com os profissionais responsáveis.

## Tecnologias
- HTML5 semântico
- CSS3 responsivo
- JavaScript sem dependências

As fotografias são carregadas do Unsplash e as fontes do Google Fonts.
